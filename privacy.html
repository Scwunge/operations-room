Privacy policy

Last updated: 2 November 2026

Operations Room is a private tool used only by its owner to manage the owner's own YouTube channels.

What it accesses

When the owner signs in with Google, the tool asks for access to the owner's YouTube account so it can upload the owner's videos, update their titles, descriptions and thumbnails, and read the owner's own channel and video statistics (YouTube Data API and YouTube Analytics API).

How data is used and stored

  • Data is used only to perform those actions for the owner.
  • Sign-in tokens and any data read from YouTube are stored only on the owner's own computer. Nothing is sent to any other server, sold, shared, or used for advertising.
  • The tool does not collect data about any other person.

Google API Services User Data Policy

Operations Room's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions. Deleting the tool's local data folder removes everything it stored.
